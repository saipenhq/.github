This document answers one boring but useful question: **what belongs where?**

## Ownership model

- **SAIPEN HQ** — public organization and ecosystem identity: https://github.com/saipenhq
- **vacterro** — current author and GitHub owner of the linked project repositories: https://github.com/vacterro
- **SAIPEN Community** — shared discussion layer: https://discord.gg/SEYaYkuVgN

A project may be part of the SAIPEN ecosystem without being physically owned by the
SAIPEN HQ GitHub organization.

## Updating this map

Update this file when one of these facts changes:

1. a project is created, archived, or retired;
2. a project's role materially changes;
3. a repository is actually transferred to or from SAIPEN HQ;
4. a project stops being part of the shared public network.

README links are navigation. This file is the canonical taxonomy.
