# SAIPEN HQ · .github

Shared GitHub organization metadata for [SAIPEN HQ](https://github.com/saipenhq).

This repository owns the organization profile and default community-health files.
Repository-local files override these defaults when a project needs a stricter or
more specific contract.

- Organization profile: [`profile/README.md`](profile/README.md)
- Contribution defaults: [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Support routing: [`SUPPORT.md`](SUPPORT.md)
- Security reporting: [`SECURITY.md`](SECURITY.md)
- Community conduct: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
- Community: [SAIPEN Discord](https://discord.gg/SEYaYkuVgN)
