# Support

## Where to ask

- **Quick question, screenshot, idea, or cross-project discussion:** [SAIPEN Community on Discord](https://discord.gg/SEYaYkuVgN)
- **Reproducible bug:** open an issue in the repository that owns the affected code.
- **Durable feature request:** use the owning repository's issue tracker.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md); do not post sensitive vulnerability details in a public issue.

## Before reporting a bug

Check the project's README, current release notes, and existing issues first.
Include enough environment and reproduction detail for another person to verify
the problem without guessing.

SAIPEN HQ does not provide a guaranteed response-time SLA. Projects are developed
and maintained according to their own scope and release cadence.
